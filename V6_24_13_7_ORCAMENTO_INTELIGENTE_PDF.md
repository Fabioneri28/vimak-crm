# V6.24.13.7 — Orçamento Inteligente por PDF
Nova etapa em PROPOSTAS: Orçamento por PDF.

Fluxo: PDF → leitura local → ambientes → especificações → cotas → conferência → valor preliminar → proposta.

A primeira versão usa PDF.js para PDFs com camada de texto. PDFs totalmente escaneados/imagem exigirão uma futura camada de visão/OCR/IA.
O sistema não inventa preço: o valor preliminar é informado/conferido por ambiente.
Nenhuma migration nova e nenhuma alteração no Supabase.
